# 数据文件说明

本项目的训练脚本和 Notebook 默认读取：

```text
data/手写数字识别.csv
```

当前对话上传的是修改后的 Notebook 和一张 `demo.png`，**没有包含训练用 CSV**。因此仓库中不提供虚构的数据集；请把你本机已有的 `手写数字识别.csv` 放到本目录。

## CSV 格式要求

- 第一列：数字标签，取值为 `0` 到 `9`。
- 后面恰好 784 列：28×28 图像展开后的像素特征。
- 每行代表一张图片。
- 像素值应为 `0` 到 `255` 的灰度值。程序会将特征除以 255，缩放到 `0` 到 `1`。
- 第一列之后不要额外保留 Pandas 索引列。

示意（这里只展示列结构，不是真实数据）：

```text
label,pixel0,pixel1,...,pixel783
5,0,0,...,0
0,0,12,...,0
```

如果你的数据集列名不同，只要第一列确实是标签、后面 784 列确实是像素值，也可以使用。

## 关于 `demo.png`

`demo.png` 是用于演示预测的 28×28 灰度图片。推荐图片约定为：黑色背景、白色笔画，与常见 MNIST 数据的视觉方向一致。若你的图片是白色背景、黑色笔画，运行预测时使用 `--invert`。
